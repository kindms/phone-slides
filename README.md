# 手機簡報 phone-slides

沒有投影機時，用每個人的手機看簡報：講者翻到哪一張，聽眾手機就跟到哪一張，聽眾不能自己往後翻。

## 怎麼用

1. 把 PPT 檔拖到 `轉換簡報.bat` 上（電腦要有 PowerPoint）。它會把每張投影片轉成圖片、抓出備忘稿，並上傳到網路。
2. 等 1～2 分鐘，打開 `簡報連結.txt`：
   - **講者遙控**：只給自己，用手機或電腦打開；可以看到備忘稿和下一張預覽。
   - **聽眾連結**：在講者遙控頁按「QR Code」，讓大家掃描。
3. 上台後按「開始簡報」。按鈕、左右滑動、鍵盤方向鍵或簡報筆都能翻頁。

## 小提醒

- 聽眾的手機只會收到「目前這張」圖片，看不到後面的內容。
- 「黑畫面」可以暫時讓大家看你，不看手機；「結束簡報」會顯示謝謝畫面。
- 講者頁重新整理或換一台裝置打開，會從上次的位置接續。
- 同步走 QuizLive（kaho）同一個 Firebase 資料庫的 `rooms/ps_房號`。
